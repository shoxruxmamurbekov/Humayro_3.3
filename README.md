# HUMAYRO 3.3 — Global Intelligence UI

Premium frontend reference for integrating an intelligence-first visual system into Humayro 3.2.

**This is not a backend replacement.** Google AI Studio must inspect Humayro 3.2 first, then adapt this UI while preserving existing API contracts, AI services, news aggregation, authentication, globe data and business logic.

## Run
`npm install`
`npm run dev`

## Design
News → Signal → AI analysis → Regional context → Historical parallel → Insight.

See `GOOGLE_AI_STUDIO_PROMPT.md` for the migration rules.
